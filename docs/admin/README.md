# 後台（admin）功能規劃

此資料夾收集日後開發後台管理介面時，各伺服器功能的資料表、邏輯與管理需求。每個功能一份文件，內容固定包含：

1. Java 對照來源與 Go 實作位置
2. 資料表結構與伺服器讀取時機（是否需 reload）
3. 目前的管理方式（SQL 或 GM 指令）
4. 後台功能規劃：必要、建議、技術注意事項
5. 驗證方式
